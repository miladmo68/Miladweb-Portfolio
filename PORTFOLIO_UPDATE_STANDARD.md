# Portfolio publishing standard

Every production-ready portfolio project must also be added to this website.

## Web app entries

- Add the project to the `PROJECTS` array in `src/components/Project.jsx`.
- Use the real project screenshot, production name, and verified live URL.
- Set `cat: "app"` so the card appears under **Web App**, not Web Design.
- Place the strongest and newest work near the top while keeping a curated order.
- Keep the existing Preview and Visit interactions working.
- Verify the production build and both the All and Web App views before publishing.

## Asset rules

- Store the optimized screenshot in `src/assets/img/`.
- Use a descriptive lowercase filename.
- Confirm the image remains readable in the existing 16:9 card crop.
